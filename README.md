## 💻 Local Development

Clone the repository and run the local development server:

```bash
# Clone the repository
git clone https://github.com/nishu352/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Available Scripts

- `npm run dev` — Launch development server with Turbopack on port 3000
- `npm run build` — Build production application bundle
- `npm run start` — Run production server
- `npm run lint` — Execute ESLint syntax and style analysis
